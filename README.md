# 作文メーカー（子どもとSNS）

学生が自分で内容を考え、接続表現を使って意見文を組み立てるための練習ツールです。

公開URL: https://chiaki2027.github.io/sakubun/

## 流れ

0. お手本の作文（テーマ：学校の制服）の各文の「役わり」を選び、意見文の設計図を知る
1. 一問一答で、テーマについての質問（10問）に答える
   - 理由ごとに「たとえば？」と深掘りする
   - 反対意見の「なるほど」と思うところ（みとめる）と、それへの反論を書く
2. 答えがそのまま順番にならぶ
3. 表現リスト（順番はランダム）から表現をえらんで、作文の好きな場所に入れる
   - 「～」のある表現は、クリックした場所の後ろの文をはさむ形で入る
   - つながりがおかしい部分に赤線が引かれ、「つなげてみよう」画面で学生が直す
   - アプリが「。」「ます・です」の残り、「〜だことだ」、「わたしは」の重複などをチェックし、正しくつながったら作文に入る
4. 読みなおして完成させ、画像（PNG）で保存する

入力内容はブラウザに自動で保存されるので、ページを再読み込みしても続きから再開できます。
