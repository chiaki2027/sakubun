# 作文メーカー（子どもとSNS）

学生が自分で内容を考え、接続表現を使って意見文を組み立てるための練習ツールです。

公開URL: https://chiaki2027.github.io/sakubun/

## 流れ

1. お手本を読む：お手本の作文（テーマ：学校の制服）の各文の「役わり」を選ぶ。最後に意見文の構成（空欄つきの全文）を見て、スクリーンショットする
2. しつもんに答える：一問一答で10問に答える
   - 理由ごとに「たとえば？」と深掘りする
   - 反対意見の「なるほど」と思うところ（みとめる）と、それへの反論を書く
3. 構成にあてはめる：構成の全文の空欄をタップし、自分の答えから選んであてはめる
   - 役割に合わない答えを選ぶとヒントが出る
   - あてはめたら「つなげてみよう」画面で、つながるように書き直す（「。」「ます・です」の残り、「〜だことだ」、「たとえば」「確かに」「わたしは」の重複をチェック）
4. 紙に書く：完成した作文の全文を見ながら、紙に書く（画像で保存もできる）

画面の説明文にはルビがつき（オン・オフ可）、英語・ネパール語の翻訳を表示できます。

入力内容はブラウザに自動で保存されるので、ページを再読み込みしても続きから再開できます。

## ver.2（空欄に直接書くタイプ）

公開URL: https://chiaki2027.github.io/sakubun/v2/

1. お手本を読む：ver.1 と同じ
2. 空欄をうめる：構成の文（例：「1つ目は、（　）ことだ。」）が表示され、空欄に入ることばを自分で書く
   - 「次へ」を押すと、つながりをチェックする（「。」「ます・です」の残り、「〜だことだ」、空欄の後ろのことば（こと・という・と思う）の重複、「たとえば」「確かに」「わたしは」の重複）
   - まちがいがあると、つながった文に赤線を引いて、なおし方を表示する
   - 下に「ここまでの作文」が表示され、書いた文が構成の順番で並んでいく
3. 紙に書く：完成した作文の全文を見ながら、紙に書く（画像で保存もできる）

ver.1 と ver.2 は入力データを別々に保存します。

## ファイル

- `index.html` … ver.1 のアプリ本体（このファイルだけで動きます）
- `v2/index.html` … ver.2 のアプリ本体
